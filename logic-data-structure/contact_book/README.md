# 📒 Contact Book (Python OOP)

A console-based Contact Book application built using Python and Object-Oriented Programming (OOP). It allows users to store and manage contact information using a menu-driven interface.

## Features

- ➕ Add a contact
- 📋 View all contacts
- 🔍 Search for a contact
- ✏️ Update contact details
- 🗑️ Delete a contact
- 🚪 Exit the application

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
