# 📖 Word Count Tool (Python OOP)

A console-based Word Count Tool built using Python and Object-Oriented Programming (OOP). It analyzes text and displays useful statistics such as the number of words, characters, sentences, and the frequency of each word.

## Features

- 📝 Count total words
- 🔤 Count total characters
- 📄 Count total sentences
- 📊 Display word frequency
- 🔠 Case-insensitive analysis

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## Project Structure


- Classes and Objects

