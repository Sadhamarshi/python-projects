# 💰 Expense Tracker (Python OOP)

A console-based Expense Tracker built using Python and Object-Oriented Programming (OOP). It helps users record, view, search, and delete expenses while calculating the total amount spent.

## Features

- ➕ Add a new expense
- 📋 View all expenses
- 🔍 Search expenses by category
- 🗑️ Delete an expense
- 💵 Calculate total expenses
- 🚪 Exit the application

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
