# 📝 Console-Based To-Do List (Python OOP)

A simple console-based To-Do List application built using **Python** and **Object-Oriented Programming (OOP)** principles. This project allows users to manage their daily tasks through a menu-driven interface.

## Features

- ➕ Add a new task
- 📋 View all tasks
- ✅ Mark a task as completed
- 🗑️ Delete a task
- 🚪 Exit the application

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/Sadhamarshi/python-projects.git
```

2. Navigate to the project folder.

```bash
cd python-projects/oop/todo_list
```

3. Run the application.

```bash
python main.py
```
