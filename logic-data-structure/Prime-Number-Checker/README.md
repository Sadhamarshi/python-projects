# 🔢 Prime Number Checker (Python OOP)

A console-based Prime Number Checker built using Python and Object-Oriented Programming (OOP). It determines whether a given integer is prime using an optimized algorithm that checks divisibility only up to the square root of the number.

## Features

- 🔍 Check if a number is prime
- ⚡ Optimized algorithm using √n
- ✅ Handles invalid input gracefully
- 💻 Console-based interface

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- math Module
