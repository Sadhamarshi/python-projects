# 🎯 Hangman Game (Python OOP)

A console-based Hangman game built using Python and Object-Oriented Programming (OOP). The player guesses letters to reveal a hidden word before running out of attempts.

## Features

- Random word selection
- Letter-by-letter guessing
- Tracks guessed letters
- Limited number of attempts
- Win/Lose messages
- Input validation

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
