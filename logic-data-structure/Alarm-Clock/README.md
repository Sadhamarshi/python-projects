# ⏰ Alarm Clock (Python OOP)

A console-based Alarm Clock built using Python and Object-Oriented Programming (OOP). Users can set an alarm time, and the application continuously checks the current system time until the alarm is triggered.

## Features

- ⏰ Set an alarm using 24-hour format
- 🕒 Displays the current time every second
- 🔔 Triggers an alarm message at the specified time
- 💻 Console-based interface

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- datetime Module
- time Module
