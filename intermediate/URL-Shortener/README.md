# URL Shortener (Python)

A simple command-line URL Shortener built with Python.

## Features

- Shorten long URLs
- Retrieve original URLs
- Store data in a JSON file
- Prevent duplicate URLs
- Generate unique short codes
- Menu-driven interface

## Technologies Used

- Python
- JSON
- File Handling

## Project Structure

```
URL-Shortener/
│
├── main.py
├── shortener.py
├── storage.py
├── utils.py
├── urls.json
├── README.md
└── requirements.txt
```

## How to Run

```bash
python main.py
```
